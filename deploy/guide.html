Код шинэчлэх ба өгөгдөл sync хийх

Компьютер дээрээ хийсэн өөрчлөлтийг серверт хэрхэн гаргах, мөн сервер ба локалын хооронд өгөгдлийг хэрхэн зөөхийг нэг дор. Бүх үйлдэл нэг командаар хийгдэнэ.

Агуулга
  1. Юу хаашаа явдаг вэ
  2. Нэг удаагийн тохиргоо
  3. Код шинэчлэх
  4. Сервер → Локал
  5. Локал → Сервер
  6. Буцаах

Юу хаашаа явдаг вэ

Компьютеркод бичих, турших
код npm run deploy
өгөгдөл npm run sync:pull
өгөгдөл npm run sync:push
Серверlearn.yesuvd.tech

Код болон өгөгдөл хоёр тусдаа явдаг. Код шинэчлэхэд серверийн өгөгдөл (сурагчид, шалгалт, илгээсэн файлууд) огт хөндөгдөхгүй.

Sync нь нэгтгэдэггүй, солидог

Өгөгдлийг нэг талаас нөгөө рүү зөөхөд хүлээн авагч талын өгөгдөл бүхэлдээ солигдоно. Хоёр талд тусад нь хийсэн өөрчлөлтийг нийлүүлэх боломжгүй. Тиймээс сервер бол үндсэн эх: контент, дүнг сервер дээр оруулна, локал дээр зөвхөн туршина.

Хүсэж буй зүйлКомандЮу солигдох вэ
Шинэ функц, засварыг серверт гаргахnpm run deployЗөвхөн код. Өгөгдөл хэвээр.
Серверийн бодит өгөгдлөөр локалаар туршихnpm run sync:pullЛокал өгөгдөл. Сервер хөндөгдөхгүй.
Локал дээр бэлдсэнээ серверт бүхэлд нь тавихnpm run sync:pushСерверийн өгөгдөл бүхэлдээ.
Sync-ийг буцаах (локал)npm run sync:restore-localЛокал өгөгдөл нөөцөөр.

Нэг удаагийн тохиргоо ~5 минут

Эдгээрийг нэг л удаа хийнэ. Дараа нь бүх үйлдэл нууц үг асуухгүйгээр нэг командаар ажиллана.

  1. Серверийн хаягийг хадгалах

    SERVER_IP-ийн оронд серверийн IP-г бичээд, дараа нь PowerShell-ээ хааж шинээр нээнэ.

    КомпьютерPowerShell
    [Environment]::SetEnvironmentVariable('SURGALT_SERVER', 'root@SERVER_IP', 'User')

  2. SSH түлхүүр үүсгэж серверт бүртгэх

    Энэ алхмын дараа скриптүүд серверийн нууц үгийг дахин асуухгүй.

    Түлхүүр аль хэдийн байвал шинээр бүү үүсгэ

    $env:USERPROFILE\.ssh\id_ed25519.pub файл байгаа бол (жишээ нь GitHub-т ашигладаг) ssh-keygen-ийг алгасна. Шинээр үүсгэвэл хуучин түлхүүр дарагдаж GitHub-ийн эрх алдагдана.

    Компьютерзөвхөн түлхүүр байхгүй үед
    ssh-keygen -t ed25519

    Түлхүүрээ серверт бүртгэнэ (серверийн нууц үгийг сүүлчийн удаа асууна):

    КомпьютерPowerShell
    type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh $env:SURGALT_SERVER "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

    Шалгах: ssh $env:SURGALT_SERVER "echo ok" нууц үг асуухгүйгээр ok гэж хариулах ёстой.

  3. Серверт шинэ скриптүүдийг татах

    Энэ хувилбарт нэмэгдсэн update.sh серверт байхгүй тул эхний удаа гараар татна. Эхлээд компьютер дээрээ commit, push хийгээд:

    Серверssh-ээр нэвтэрсний дараа
    cd /opt/surgalt && git pull && chmod +x deploy/*.sh

Код шинэчлэх өгөгдөл хөндөгдөхгүй

  1. Локал дээр өөрчилж, турших

    npm run dev ажиллуулаад http://localhost:3000 дээр шалгана.

  2. Commit хийх

    Компьютер
    git add -A
git commit -m "Юу өөрчилснөө товч бичнэ"

  3. Серверт гаргах

    Компьютер
    npm run deploy

    Энэ нэг команд дараалан:

    • commit хийгээгүй өөрчлөлт байвал зогсоно;
    • кодыг GitHub руу git push хийнэ;
    • сервер дээр өгөгдлийг нөөцөлнө;
    • шинэ кодыг татаж, Docker image-ийг дахин build хийнэ;
    • апп асаж, эрүүл ажиллаж байгааг шалгана.

    Дууссаны дараа хөтөч дээр Ctrl+F5 дарж шинэчилнэ.

Сервер дээр шууд ажиллуулах

Компьютер дэргэд байхгүй үед (жишээ нь GitHub дээр шууд засвар хийсэн бол) сервер дээр /opt/surgalt/deploy/update.sh ажиллуулахад ижил үр дүн гарна.

Сервер → Локал сервер хөндөгдөхгүй

Серверийн бодит өгөгдлөөр (сурагчид, шалгалт, хичээл, илгээсэн файлууд) локал дээрээ турших, алдаа хайхад хэрэглэнэ.

КомпьютерDocker Desktop асаалттай байх
npm run sync:pull

Скрипт дараалан хийх зүйлс:

  1. сервер дээр нөөц үүсгэж татна;
  2. одоогийн локал өгөгдлийг .sync/ хавтсанд нөөцөлнө;
  3. солихоос өмнө yes гэж баталгаажуулахыг хүснэ;
  4. локал өгөгдлийг серверийнхээр сольж, тоог харуулна.
Локал дээр оруулсан зүйл алга болно

Локал дээр оруулсан контент серверийнхээр солигдоно. Хэрэв хадгалах зүйл байсан бол буцааж болно. Локал нөөцөөс сүүлийн 10 нь хадгалагдана.

Локал → Сервер серверийн өгөгдөл солигдоно

Ховор хэрэглэнэ

Сервер дээрх бүх өгөгдөл локалынхаар солигдоно. Үүнд:

  • сурагчдын илгээсэн даалгавар, файлууд;
  • өгсөн шалгалтын хариу, дүн;
  • сервер дээр шинээр оруулсан хичээл, хэрэглэгч, нууц үгийн өөрчлөлт.

Хичээл эхэлсний дараа энийг бараг хэрэглэхгүй. Шинэ хичээл, шалгалтыг сервер дээр шууд эсвэл AI импортоор оруулна.

Хэрэглэх тохиолдол: анх серверт өгөгдөл шилжүүлэх, эсвэл сервер дээр ямар ч үйл ажиллагаа явагдаагүй байхад бэлтгэлээ бүхэлд нь тавих.

КомпьютерDocker Desktop асаалттай байх
npm run sync:push

Солихоос өмнө сервер дээр автоматаар нөөц үүсч, yes гэж баталгаажуулахыг хүснэ. Солигдсоны дараа бүх хэрэглэгч дахин нэвтэрнэ.

Буцаах

Локал өгөгдлийг sync-ээс өмнөх төлөвт

sync:pull дуусахад яг ажиллуулах командыг хэвлэдэг. Нөөцийн нэр мэдэхгүй бол командыг файлын нэргүй ажиллуулахад жагсаалтыг харуулна.

Компьютер
npm run sync:restore-local -- local-backup-20261001-1030.archive.gz

Серверийн өгөгдлийг нөөцөөс

Сервер өдөр бүр 03:00-д болон шинэчлэл, sync бүрийн өмнө нөөц үүсгэдэг.

Сервер
cd /opt/surgalt/deploy
ls -t backups/ | head -5          # сүүлийн нөөцүүд
./restore.sh backups/surgalt-20261001-0300.archive.gz

Кодыг өмнөх хувилбарт

update.sh алдаа гарвал буцаах командыг өөрөө хэвлэдэг. Гараар хийх бол:

Сервер
cd /opt/surgalt
git log --oneline -5                # хувилбарууд
git checkout ХУВИЛБАРЫН_КОД
cd deploy && docker compose up -d --build app

Засвараа push хийсний дараа git checkout main хийгээд ./update.sh ажиллуулна.

Асуудал гарвал

«Серверийн хаяг тохируулаагүй»

Нэг удаагийн тохиргооны 1-р алхмыг хийгээд PowerShell (эсвэл VS Code)-оо бүрэн хааж дахин нээнэ.

«Docker Desktop асаагүй байна»

Sync скриптүүд MongoDB-ийн хэрэгслийг Docker-оор ажиллуулдаг. Docker Desktop-ийг асааж, доод буланд «Engine running» болсны дараа дахин оролдоно.

Нууц үг байнга асуугаад байна

SSH түлхүүр бүртгэгдээгүй байна. Тохиргооны 2-р алхмыг давтана.

«Commit хийгээгүй өөрчлөлт байна»

npm run deploy зөвхөн commit хийсэн кодыг гаргадаг. git add -A, git commit -m "…" хийгээд дахин ажиллуулна.

Шинэчилсний дараа сайт ажиллахгүй байна

Сервер дээр аппын логийг харна:

Сервер
cd /opt/surgalt/deploy && docker compose ps && docker compose logs --tail 50 app

Шалтгаан тодорхойгүй бол кодыг өмнөх хувилбарт буцааж, логийг хөгжүүлэгчид илгээнэ.

PowerShell «running scripts is disabled» гэвэл

npm run … командууд энэ хязгаарыг тойрдог. Скриптийг шууд ажиллуулсан бол оронд нь npm run хэлбэрийг ашиглана.

Скриптүүд: deploy/sync/ (компьютер), deploy/update.sh, backup.sh, restore.sh (сервер). Дэлгэрэнгүй: deploy/DEPLOY.md.
