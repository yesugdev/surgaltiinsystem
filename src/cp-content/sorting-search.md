## 🎯 Энэ сэдвээс юу сурах вэ
- Стандарт эрэмбэлэлтийг зөв ашиглах (өөрийн дүрмээр ч)
- Хоёртын хайлтаар эрэмбэлэгдсэн өгөгдлөөс O(log n)-д хайх
- **Хариуг хоёртын хайлтаар олох** — олимпиадын хамгийн хүчтэй техникүүдийн нэг

## 💡 Гол санаа
### Эрэмбэлэлт
Өгөгдлийг эрэмбэлбэл олон бодлого хялбар болдог: ижил утгууд хажуу хажуудаа, хамгийн бага нь эхэнд гэх мэт. Стандарт `sort` нь **O(n log n)** — өөрөө бичих шаардлагагүй.

### Хоёртын хайлт
Толь бичгээс үг хайхдаа эхнээс нь уншдаггүй — **дундаас нь нээж**, аль хагаст байгааг шийдээд, нөгөө хагасыг хаядаг. Алхам бүрт хайх хүрээ **хоёр дахин** багасна → 10⁶ элементийг ≈ 20 алхамд хайна.

## 🧠 Алхам алхмаар: хариуг хоёртын хайлтаар олох
**Бодлого (Factory Machines):** n машин, i-р машин нэг бүтээгдэхүүнийг tᵢ секундэд хийнэ. t бүтээгдэхүүн хийх хамгийн бага хугацааг ол.

1. «T секундэд хэдэн бүтээгдэхүүн хийх вэ?» гэдгийг хялбар тооцно: Σ ⌊T / tᵢ⌋.
2. `ok(T)` = «T секундэд t-ээс багагүй хийж чадах уу?» — T өсөхөд **false…false, true…true** (монотон).
3. Тиймээс хамгийн эхний `true`-г хоёртын хайлтаар олно.

```
T:     1  2  3  4  5  6  7  8
ok:    F  F  F  F  T  T  T  T     ← эхний T-г хайна
```

## 💻 Код
Эрэмбэлэлт:
```cpp
sort(a.begin(), a.end());                         // өсөхөөр
sort(a.begin(), a.end(), greater<int>());         // буурахаар
sort(v.begin(), v.end(), [](auto &x, auto &y) {   // өөрийн дүрэм
    return x.second < y.second;
});
```
Эрэмбэлэгдсэн массивт хайх:
```cpp
int i = lower_bound(a.begin(), a.end(), x) - a.begin(); // x-ээс багагүй эхний байрлал
int j = upper_bound(a.begin(), a.end(), x) - a.begin(); // x-ээс их эхний байрлал
int cnt = j - i;                                         // x хэдэн удаа байгаа
```
Хариуг хоёртын хайлтаар олох (Factory Machines):
```cpp
// T секундэд t-ээс багагүй бүтээгдэхүүн хийж чадах уу?
auto ok = [&](ll T) {
    ll made = 0;
    for (ll x : machines) {
        made += T / x;
        if (made >= t) return true;   // эрт зогсоно — нийлбэр халихаас сэргийлнэ
    }
    return false;
};
ll lo = 0, hi = *min_element(machines.begin(), machines.end()) * t;  // hi үед заавал хүрнэ
while (lo < hi) {
    ll mid = lo + (hi - lo) / 2;
    if (ok(mid)) hi = mid;            // mid хангалттай → зүүн тийш
    else lo = mid + 1;
}
cout << lo << "\n";
```

## ⏱️ Нарийн төвөгшил
- Эрэмбэлэлт: O(n log n)
- Нэг хайлт: O(log n)
- Хариуг хайх: O(log(хүрээ) · ok-ийн хугацаа)

## ⚠️ Түгээмэл алдаа
- Хоёртын хайлтын **төгсгөлгүй давталт**: `lo = mid` гэж бичвэл гацаж болно. Дээрх загвараа (`hi = mid`, `lo = mid + 1`) цээжил.
- `hi`-г хэт бага сонгох — хариу хүрээнд багтахгүй.
- `(lo + hi) / 2` халих — `lo + (hi - lo) / 2` гэж бич.
- Эрэмбэлэгдээгүй массивт `lower_bound` ашиглах.
- `ok()` функц монотон биш байх — тэгвэл хоёртын хайлт ажиллахгүй.
