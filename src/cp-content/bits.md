## 🎯 Энэ сэдвээс юу сурах вэ
- Тоог хоёртын (0/1) хэлбэрээр харах
- AND, OR, XOR, шилжүүлэх үйлдлүүд
- **Bitmask**-аар дэд олонлогийг илэрхийлж, бүх дэд олонлогийг давтах

## 💡 Гол санаа
Компьютер тоог **битүүдээр** хадгалдаг: 13 = `1101₂` = 8 + 4 + 1. Бит бүр «байна/байхгүй» гэсэн шийдвэр гэж үзвэл нэг тоо **олонлогийг** бүхэлд нь илэрхийлнэ.

Жишээ: {А, Б, В, Г} гэсэн 4 сурагчаас {А, В}-г сонгосон бол `0101₂` = 5.

| Үйлдэл | C++ | Утга |
|---|---|---|
| AND | `a & b` | хоёуланд нь 1 байгаа битүүд |
| OR | `a \| b` | аль нэгэнд нь 1 |
| XOR | `a ^ b` | ялгаатай битүүд |
| Зүүн шилжүүлэх | `1 << k` | 2ᵏ |
| k-р бит асаалттай эсэх | `(x >> k) & 1` | 0 эсвэл 1 |
| k-р битийг асаах | `x \| (1 << k)` | |
| k-р битийг унтраах | `x & ~(1 << k)` | |

## 🧠 Алхам алхмаар: бүх дэд олонлог
n элементийн бүх дэд олонлог нь `0`-ээс `2ⁿ − 1` хүртэлх тоо. n = 3 бол:

| mask | бит | олонлог |
|---|---|---|
| 0 | 000 | {} |
| 1 | 001 | {a₀} |
| 5 | 101 | {a₀, a₂} |
| 7 | 111 | {a₀, a₁, a₂} |

## 💻 Код: «Apple Division» төрлийн бодлого
n ≤ 20 алимыг хоёр бүлэгт хувааж, жингийн ялгааг хамгийн бага болго.
```cpp
long long best = LLONG_MAX, total = 0;
for (auto w : a) total += w;
for (int mask = 0; mask < (1 << n); mask++) {
    long long s = 0;
    for (int k = 0; k < n; k++)
        if (mask >> k & 1) s += a[k];
    best = min(best, llabs(total - 2 * s));
}
```

### XOR-ын гайхалтай шинж
`x ^ x = 0`, `x ^ 0 = x`. Тиймээс бүх тоо хоёр удаа, **ганцхан нь нэг удаа** гарсан бол бүгдийг XOR хийхэд тэр тоо үлдэнэ.

## ⏱️ Нарийн төвөгшил
Бүх дэд олонлог: **O(2ⁿ · n)** — n ≤ 20 хүртэл (≈ 2·10⁷) багтана.

## ⚠️ Түгээмэл алдаа
- Үйлдлийн дараалал: `x & 1 == 0` нь `x & (1 == 0)` болдог! Үргэлж хаалт тавь: `(x & 1) == 0`.
- `1 << 40` нь C++ `int`-д халина → `1LL << 40`.
- n = 25-аас дээш бол 2ⁿ хэт их — өөр арга (DP) хэрэгтэй.

## 🏋️ Дасгал (CSES)
1. **Apple Division** — бүх дэд олонлог
2. **Gray Code** — XOR, `i ^ (i >> 1)`
3. **Missing Number** — XOR-оор шийдэж үз
