## 🎯 Энэ сэдвээс юу сурах вэ
- Код бичихээсээ **өмнө** алгоритм хугацаандаа багтах эсэхийг тооцоолох
- Big-O тэмдэглэгээг унших, бичих
- Хурдан оролт/гаралт, том тоотой ажиллах

## 💡 Гол санаа
Шүүгч таны кодыг **хугацааны хязгаар** (ихэвчлэн 1 секунд) дотор дуусахыг шаарддаг. Алгоритмын хурдыг секундээр биш, **оролтын хэмжээ n өсөхөд үйлдлийн тоо хэрхэн өсөх**-өөр хэмжинэ. Үүнийг **Big-O** гэнэ.

Энгийн жишээ: ангийн 30 сурагчаас хамгийн өндрийг олохын тулд хүн бүрийг нэг удаа харна — **O(n)**. Харин бүх хос сурагчийг харьцуулбал — **O(n²)**.

| Код | Нарийн төвөгшил |
|---|---|
| Нэг давталт `for i in range(n)` | O(n) |
| Давхар давталт | O(n²) |
| Хоёр дахин хуваах (хоёртын хайлт) | O(log n) |
| Эрэмбэлэх | O(n log n) |
| Бүх дэд олонлог | O(2ⁿ) |
| Бүх сэлгэмэл | O(n!) |

### Хамгийн чухал дүрэм
C++ програм шүүгч дээр **1 секундэд ойролцоогоор 10⁸** энгийн үйлдэл хийдэг. Олимпиадад C++ ашигладаг гол шалтгаан нь энэ хурд.

## 🧠 Хязгаараас алгоритмыг таах
Бодлогын **n-ийн хязгаар** нь ямар алгоритм хүлээгдэж байгааг шууд хэлдэг:

| n ≤ | Хүлээгдэж буй | Ихэвчлэн |
|---|---|---|
| 10 | O(n!) | бүх сэлгэмэл |
| 20 | O(2ⁿ) | бүх дэд олонлог, bitmask |
| 500 | O(n³) | гурвалсан давталт, Floyd |
| 5 000 | O(n²) | давхар давталт, DP |
| 10⁵ – 10⁶ | O(n log n) | эрэмбэлэлт, хоёртын хайлт, segment tree |
| 10⁷ | O(n) | нэг давталт, prefix sum |
| 10¹⁸ | O(log n) эсвэл O(1) | томьёо, хурдан зэрэг |

**Жишээ:** n ≤ 2·10⁵ бол O(n²) = 4·10¹⁰ үйлдэл — хэтэрнэ ❌. O(n log n) ≈ 3.6·10⁶ — багтана ✅.

## 💻 Олимпиадын C++ загвар
Бодлого бүрийг энэ загвараас эхлүүл:
```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);   // cin/cout-ыг хурдасгана
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;

    ll sum = 0;
    for (ll x : a) sum += x;
    cout << sum << "\n";           // endl биш "\n"
}
```

### Төрлүүдийн хүрээ
| Төрөл | Хүрээ | Хэзээ |
|---|---|---|
| `int` | ≈ ±2.1·10⁹ | n, индекс, жижиг утга |
| `long long` | ≈ ±9.2·10¹⁸ | нийлбэр, үржвэр, хариу |
| `double` | ≈ 15 оронтой нарийвчлал | бутархай (болгоомжтой!) |

## ⚠️ Түгээмэл алдаа
- **Тоо халих (overflow):** `int a = 1e5; a * a` → халина! Нийлбэр, үржвэр томорч болох бол `long long`. Үржихийн өмнө: `(ll)a * a`.
- `endl` ашиглах — гаралт бүрт буфер хоослох тул удаан. `"\n"` ашигла.
- `ios::sync_with_stdio(false)`-ийн дараа `scanf/printf`-тэй **холих** — гаралт холилдоно.
- Том массивыг `main` дотор зарлах (`int a[1000000]`) → stack халина. `vector` эсвэл глобал хувьсагч ашигла.
