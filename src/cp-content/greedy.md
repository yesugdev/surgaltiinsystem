## 🎯 Энэ сэдвээс юу сурах вэ
- Шуналт (greedy) алгоритм гэж юу вэ, хэзээ **зөв**, хэзээ **буруу** вэ
- Сонгодог greedy бодлогууд: ажил сонгох, хуваарь, зоос
- Greedy-ийн зөвийг «солих аргумент»-аар батлах

## 💡 Гол санаа
Greedy алгоритм алхам бүрт **тухайн мөчийн хамгийн сайн** сонголтыг хийж, түүнийгээ дахин эргэж хардаггүй. Хурдан бөгөөд кодлоход хялбар, гэхдээ **үргэлж зөв биш**.

**Буруу болох жишээ:** зоосны төрөл {1, 3, 4}, 6-г хамгийн цөөн зоосоор. Greedy: 4 + 1 + 1 = **3 зоос**. Зөв хариу: 3 + 3 = **2 зоос**. ❌
Ийм үед DP хэрэгтэй.

### Солих аргумент (зөвийг батлах арга)
«Хэрвээ хамгийн сайн шийдэл миний greedy сонголтыг хийгээгүй бол, түүнийг миний сонголтоор **солиход** муудахгүй» гэж харуулбал greedy зөв.

## 🧠 Алхам алхмаар: Кино наадам (Movie Festival)
n кино, тус бүр [эхлэх, дуусах] хугацаатай. Давхцахгүйгээр хамгийн олон кино үз.

| Санаа | Үр дүн |
|---|---|
| Хамгийн богиног түрүүлж | ❌ буруу (богино кино хоёр урт киног хааж болно) |
| Хамгийн эрт эхлэхийг | ❌ буруу (эрт эхэлсэн урт кино бүгдийг хаана) |
| **Хамгийн эрт дуусахыг** | ✅ зөв |

Яагаад? Эрт дуусах кино нь дараагийн кинонд **хамгийн их цаг** үлдээнэ — солих аргументаар батлагдана.

## 💻 Код
```cpp
sort(movies.begin(), movies.end(), [](auto &x, auto &y) {
    return x.second < y.second;          // дуусах хугацаагаар
});
int cnt = 0, lastEnd = 0;
for (auto [s, e] : movies)
    if (s >= lastEnd) { cnt++; lastEnd = e; }
cout << cnt << "\n";
```

### Бусад сонгодог greedy
- **Tasks and Deadlines:** хамгийн богино ажлыг түрүүлж хий.
- **Stick Lengths:** бүх тоог **медиан** руу ойртуулах нь хамгийн хямд.
- **Ferris Wheel:** хамгийн хүнд хүнийг хамгийн хөнгөнтэй нь хослуулахыг оролд (эрэмбэлэлт + хоёр заагч).

## ⏱️ Нарийн төвөгшил
Ихэнх greedy нь эрэмбэлэлт + нэг давталт: **O(n log n)**.

## ⚠️ Түгээмэл алдаа
- Батлахгүйгээр «зөв юм шиг» санаагаар бичих. **Жижиг жишээн дээр гараар шалга**, эсрэг жишээ хай.
- Буруу шинжээр эрэмбэлэх (эхлэх биш, дуусах хугацаагаар!).
- Greedy бүтэхгүй бол DP-г санаарай.
