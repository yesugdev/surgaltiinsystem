## 🎯 Энэ хичээлээр юу сурах вэ
- `string` — тэмдэгт мөр унших, хэвлэх
- Тэмдэгт бүрээр нь давтах
- Урт, харьцуулах, нэгтгэх, урвуулах
- Том/жижиг үсэг, тэмдэгт тоолох

## 💡 Санаа
Тэмдэгт мөр бол **тэмдэгтүүдийн массив**. Тиймээс массив шиг индексээр хандана.
```
индекс:  0   1   2   3   4
         h   e   l   l   o
```

## 💻 Унших ба хэвлэх
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;                     // нэг үг (хоосон зай хүртэл)
    cout << s.size() << endl;     // урт
    cout << s[0] << endl;         // эхний тэмдэгт

    string line;
    getline(cin >> ws, line);     // хоосон зайтай бүтэн мөр
}
```

## 💻 Тэмдэгт бүрээр давтах
Эгшиг тоолох:
```cpp
int cnt = 0;
for (char c : s) {                             // s-ийн тэмдэгт бүрээр
    if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') cnt++;
}
```
Индексээр:
```cpp
for (int i = 0; i < (int)s.size(); i++) cout << s[i] << ' ';
```

## 💻 Хэрэгтэй үйлдлүүд
| Код | Үр дүн (`s = "code"`) |
|---|---|
| `s.size()` | 4 |
| `s + "r"` | `"coder"` — нэгтгэх |
| `s.substr(1, 2)` | `"od"` — 1-р байрлалаас 2 тэмдэгт |
| `s == "code"` | `true` |
| `reverse(s.begin(), s.end())` | `"edoc"` (`#include <algorithm>`) |
| `toupper(s[0])` | `'C'` |

## 🧠 Палиндром (урдаас, хойноос ижил уншигддаг үг)
```cpp
bool isPal(const string& s) {
    int i = 0, j = s.size() - 1;
    while (i < j) {
        if (s[i] != s[j]) return false;   // хоёр үзүүрээс харьцуулна
        i++; j--;
    }
    return true;
}
```
`"level"` → l=l, e=e, v → **палиндром**. `"code"` → c≠e → биш.

## 💡 Тэмдэгт = тоо
Компьютерт тэмдэгт бүр **ASCII код**-той: `'a' = 97`, `'b' = 98`, …, `'0' = 48`.
```cpp
char c = '7';
int digit = c - '0';      // 7 — цифрийн тэмдэгтийг тоо болгох
char next = 'a' + 1;      // 'b'
```

## ⚠️ Түгээмэл алдаа
- `cin >> s` нь хоосон зай хүртэл л уншина — бүтэн өгүүлбэрт `getline`.
- `s[s.size()]`-д хандах — сүүлийн индекс `s.size() - 1`.
- `'a'` (тэмдэгт) ба `"a"` (мөр)-ийг андуурах.
