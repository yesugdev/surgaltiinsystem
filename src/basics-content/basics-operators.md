## 🎯 Энэ хичээлээр юу сурах вэ
- **Арифметик** оператор: `+ - * / %`
- **Харьцуулах** ба **логик** оператор
- Тооны **цифрүүдийг** `/` ба `%`-аар салгах
- Үйлдлийн **дараалал** (давуу эрэмбэ)

## 💡 Арифметик оператор
| Оператор | Утга | Жишээ | Хариу |
|---|---|---|---|
| `+` | нэмэх | `7 + 3` | 10 |
| `-` | хасах | `7 - 3` | 4 |
| `*` | үржих | `7 * 3` | 21 |
| `/` | хуваах (бүхэл тоонд — **бүхэл хэсэг**) | `7 / 3` | 2 |
| `%` | **үлдэгдэл** | `7 % 3` | 1 |

> 🍬 7 чихрийг 3 хүүхдэд тэнцүү хуваавал хүүхэд бүр `7 / 3 = 2` чихэр авч, `7 % 3 = 1` чихэр үлдэнэ.

## 💻 `/` ба `%`-ийн хэрэглээ
**Минутыг цаг, минут болгох:**
```cpp
int total = 135;
cout << total / 60 << " цаг " << total % 60 << " минут";   // 2 цаг 15 минут
```
**Тооны цифрүүд:**
```cpp
int n = 472;
int last   = n % 10;        // 2 — сүүлийн цифр
int middle = n / 10 % 10;   // 7
int first  = n / 100;       // 4
```
`n % 10` — сүүлийн цифр, `n / 10` — сүүлийн цифрийг «таслах».

**Тэгш эсэх:** `n % 2 == 0` бол тэгш.

## 💻 Товч бичиглэл
```cpp
x += 5;   // x = x + 5
x -= 2;   // x = x - 2
x *= 3;   // x = x * 3
x++;      // x = x + 1
x--;      // x = x - 1
```

## 💡 Харьцуулах оператор (хариу нь `true` / `false`)
| `==` | `!=` | `<` | `>` | `<=` | `>=` |
|---|---|---|---|---|---|
| тэнцүү | тэнцүү биш | бага | их | бага буюу тэнцүү | их буюу тэнцүү |

## 💡 Логик оператор
| Оператор | Утга | Жишээ |
|---|---|---|
| `&&` | БА — хоёулаа үнэн | `age >= 13 && age <= 19` (өсвөр нас) |
| `\|\|` | ЭСВЭЛ — аль нэг нь үнэн | `day == 6 \|\| day == 7` (амралтын өдөр) |
| `!` | ҮГҮЙСГЭЛ | `!(x > 0)` |

## 🧠 Давуу эрэмбэ
`*  /  %` нь `+  -`-ээс өмнө хийгдэнэ. Эргэлзвэл **хаалт** тавь:
```cpp
cout << 2 + 3 * 4;     // 14
cout << (2 + 3) * 4;   // 20
```

## ⚠️ Түгээмэл алдаа
- Харьцуулахдаа `=` (оноох) бичих: `if (x = 5)` ❌ → `if (x == 5)` ✅
- Сөрөг тооны үлдэгдэл: C++-д `-7 % 3 == -1` (сөрөг гарч болно).
- 0-д хуваах → програм унана.
