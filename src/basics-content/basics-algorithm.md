## 🎯 Энэ хичээлээр юу сурах вэ
- **Алгоритм** гэж юу болох
- Алгоритмыг **алхам**, **блок схем**, **псевдо код**-оор илэрхийлэх
- Анхны **C++ програмаа** бичиж ажиллуулах

## 💡 Алгоритм гэж юу вэ?
**Алгоритм** гэдэг нь ямар нэг асуудлыг шийдэх **тодорхой, дараалсан алхмууд** юм. Өдөр тутам бид алгоритм ашигладаг:

> ☕ **Цай чанах алгоритм**
> 1. Данханд ус хий.
> 2. Усыг буцалга.
> 3. Аяганд цайны уут хий.
> 4. Буцалсан усаа аяганд хий.
> 5. 3 минут хүлээ.

Сайн алгоритм:
| Шинж | Тайлбар |
|---|---|
| **Тодорхой** | Алхам бүр ганц утгатай — «бага зэрэг» гэх мэт бүдэг үг байхгүй |
| **Төгсгөлтэй** | Хязгаартай тооны алхмын дараа заавал дуусна |
| **Оролт, гаралттай** | Өгөгдөл авч (оролт), хариу гаргана (гаралт) |
| **Үр дүнтэй** | Алхам бүрийг бодитоор гүйцэтгэх боломжтой |

## 🧠 Алгоритмыг илэрхийлэх 3 арга
**1. Үгээр (алхмаар):** дээрх цайны жишээ шиг.

**2. Блок схем:**
```
  ( Эхлэл )
      ↓
  [ a, b-г унш ]        ← параллелограмм: оролт/гаралт
      ↓
  [ s = a + b ]         ← тэгш өнцөгт: үйлдэл
      ↓
  [ s-г хэвлэ ]
      ↓
  ( Төгсгөл )
```
Нөхцөл шалгах алхмыг **ромб** (◇) дүрсээр зурдаг — «Тийм / Үгүй» гэсэн хоёр гарцтай.

**3. Псевдо код** — програмчлалын хэл шиг боловч энгийн үгээр:
```
a, b-г унш
s ← a + b
s-г хэвлэ
```

## 💻 Анхны C++ програм
Компьютер алгоритмыг ойлгохын тулд түүнийг **програмчлалын хэлээр** бичнэ.
```cpp
#include <iostream>      // оролт/гаралтын сан
using namespace std;

int main() {             // програм эндээс эхэлнэ
    cout << "Hello, World!" << endl;   // дэлгэцэнд хэвлэх
    return 0;            // програм амжилттай дууслаа
}
```
| Мөр | Утга |
|---|---|
| `#include <iostream>` | `cin`, `cout` ашиглах боломж олгоно |
| `int main() { ... }` | Програмын гол хэсэг — эндээс ажиллаж эхэлнэ |
| `cout << ...` | Дэлгэцэнд (гаралт руу) хэвлэнэ |
| `;` | Команд бүрийн төгсгөл |

## 💻 Алгоритмыг кодлох: хоёр тооны нийлбэр
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;        // 1. a, b-г унш
    int s = a + b;        // 2. s = a + b
    cout << s << endl;    // 3. s-г хэвлэ
    return 0;
}
```
Блок схемийн алхам бүр кодын нэг мөр болж байгааг анзаараарай!

## ⚠️ Түгээмэл алдаа
- `;` тавихаа мартах → хөрвүүлэлтийн алдаа (*compilation error*).
- `cout`-ийг `Cout` гэж бичих — C++ **том, жижиг үсгийг ялгадаг**.
- Хэвлэх текстийг яг бодлогод заасан шиг бичихгүй байх: `Hello, World!` ба `hello world` өөр!
