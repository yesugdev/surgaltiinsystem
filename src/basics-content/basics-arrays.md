## 🎯 Энэ хичээлээр юу сурах вэ
- **Массив** — олон утгыг нэг нэрээр хадгалах
- **Индекс** 0-ээс эхэлдэг
- `vector`-ийг ашиглах
- Массивын хамгийн их, нийлбэр, урвуу дараалал

## 💡 Санаа
Ангийн 30 сурагчийн оноог хадгалахын тулд `a1, a2, …, a30` гэж 30 хувьсагч зарлах уу? Үгүй — **массив** гэдэг дугаарласан хайрцагнуудын эгнээ ашиглана.

```
индекс:   0    1    2    3    4
        ┌────┬────┬────┬────┬────┐
  a  =  │ 12 │  7 │ 25 │  3 │ 18 │
        └────┴────┴────┴────┴────┘
```
`a[0] = 12`, `a[2] = 25`. **Анхаар:** n элементтэй массивын индекс **0-ээс n−1** хүртэл.

## 💻 Массив зарлах, унших
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);              // n элементтэй массив
    for (int i = 0; i < n; i++) cin >> a[i];

    for (int i = 0; i < n; i++) cout << a[i] << " ";
    return 0;
}
```
> 💡 `vector<int> a(n);` нь хэмжээ нь оролтоос хамаардаг үед хамгийн тохиромжтой. Хэмжээ нь тогтмол бол `int a[100];` гэж ч болно.

## 🧠 Хамгийн их элемент
```cpp
int mx = a[0];                     // эхний элементээр эхлүүл
for (int i = 1; i < n; i++)
    if (a[i] > mx) mx = a[i];
cout << mx;
```
> ⚠️ `mx = 0`-ээр эхлүүлбэл бүх тоо сөрөг үед буруу болно!

## 💻 Урвуу дарааллаар хэвлэх
```cpp
for (int i = n - 1; i >= 0; i--) cout << a[i] << " ";
```

## 💻 Тоолох массив
1-ээс 10 хүртэлх тоонуудаас аль нь хэдэн удаа орсныг тоолох:
```cpp
vector<int> cnt(11, 0);            // 11 ширхэг 0
for (int i = 0; i < n; i++) cnt[a[i]]++;
for (int v = 1; v <= 10; v++) cout << v << ": " << cnt[v] << "\n";
```

## 💻 vector-ийн хэрэгтэй функцүүд
```cpp
vector<int> v;        // хоосон
v.push_back(5);       // ард нь нэмэх → {5}
v.push_back(8);       // {5, 8}
cout << v.size();     // 2
v.pop_back();         // сүүлийнхийг хасах → {5}
```

## ⚠️ Түгээмэл алдаа
- `a[n]`-д хандах — n элементтэй массивын сүүлийн индекс **n−1**. Хэтэрвэл програм унах эсвэл буруу утга гарна.
- `for (int i = 1; i <= n; i++) cin >> a[i];` гээд `vector<int> a(n)` зарлах — 1-ээс эхэлбэл `a(n + 1)` хэрэгтэй.
- Хамгийн их/багыг 0-ээр эхлүүлэх.
