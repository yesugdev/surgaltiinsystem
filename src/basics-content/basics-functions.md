## 🎯 Энэ хичээлээр юу сурах вэ
- **Функц** зарлаж, дуудах
- **Параметр** ба **буцаах утга** (`return`)
- `void` функц, утгаар ба **хаягаар** (`&`) дамжуулах

## 💡 Санаа
Функц бол **жижиг машин**: оролт (параметр) хийхэд үр дүн (буцаах утга) гаргана. Нэг удаа бичээд олон газар дуудаж ашиглана — кодоо давтахгүй, уншихад амар болно.

```
   3, 8  ──►  [ max2 ]  ──►  8
```

## 💻 Функц бичих
```cpp
#include <iostream>
using namespace std;

int max2(int a, int b) {        // буцаах төрөл, нэр, параметрүүд
    if (a > b) return a;
    return b;
}

int main() {
    cout << max2(3, 8) << endl;            // 8
    cout << max2(max2(4, 9), 6) << endl;   // 9 — функцийг дотор нь дуудаж болно
}
```
| Хэсэг | Утга |
|---|---|
| `int` | Буцаах утгын төрөл |
| `max2` | Функцийн нэр |
| `(int a, int b)` | Параметрүүд |
| `return` | Утга буцааж, функцээс гарна |

> ⚠️ Функцийг `main`-аас **өмнө** бичих (эсвэл урьдчилан зарлах) хэрэгтэй.

## 💻 bool функц: анхны тоо мөн үү?
```cpp
bool isPrime(int n) {
    if (n < 2) return false;
    for (int d = 2; d * d <= n; d++)     // √n хүртэл шалгахад хангалттай
        if (n % d == 0) return false;
    return true;
}
```
`d * d <= n` — хэрвээ n = d·k бол d ба k-ийн аль нэг нь √n-ээс их биш тул √n хүртэл шалгахад хангалттай. Ингэснээр 10⁶ хүртэлх тоог хурдан шалгана.

## 💻 void функц — утга буцаахгүй
```cpp
void printLine(int n) {
    for (int i = 0; i < n; i++) cout << '-';
    cout << '\n';
}
```

## 🧠 Утгаар ба хаягаар дамжуулах
```cpp
void addOne(int x)  { x++; }   // хуулбарыг өөрчилнө — гадна нөлөөгүй
void addOneRef(int& x) { x++; }   // жинхэнэ хувьсагчийг өөрчилнө

int a = 5;
addOne(a);     // a = 5
addOneRef(a);  // a = 6
```
`&` — «хуулбар биш, яг тэр хувьсагчийг өг» гэсэн утгатай.

## ⚠️ Түгээмэл алдаа
- Утга буцаах ёстой функцэд `return` бичихээ мартах.
- Параметрийн тоо, дарааллыг буруу өгөх: `max2(5)`.
- Функц доторх хувьсагч (локал) гадна харагдахгүй.
