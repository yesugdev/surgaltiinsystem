## 🎯 Энэ хичээлээр юу сурах вэ
- `if`, `else`, `else if`-ээр **шийдвэр** гаргах
- Хэд хэдэн нөхцөлийг `&&`, `||`-ээр нэгтгэх
- Нөхцөлийг **зөв дарааллаар** шалгах

## 💡 Санаа
Өдөр тутам: «**Хэрвээ** бороо орж байвал шүхэр ав, **эс бөгөөс** малгай өмс». Програм ч мөн нөхцөлөөс хамаарч өөр өөр үйлдэл хийнэ.

```
        ◇ бороо орж байна уу?
       /                  \
   Тийм                    Үгүй
     ↓                       ↓
 [шүхэр ав]            [малгай өмс]
```

## 💻 if / else
```cpp
int t;
cin >> t;
if (t < 0) {
    cout << "Хүйтэн" << endl;
} else {
    cout << "Хүйтэн биш" << endl;
}
```

## 💻 else if — олон сонголт
Онооноос үнэлгээ гаргах:
```cpp
int score;
cin >> score;
if (score >= 90)      cout << "A";
else if (score >= 80) cout << "B";
else if (score >= 70) cout << "C";
else if (score >= 60) cout << "D";
else                  cout << "F";
```
Дээрээс доош шалгаж, **эхний үнэн** нөхцөлийн үйлдлийг хийгээд бусдыг алгасна. Тиймээс 85 оноо → эхний `>= 90` худал, `>= 80` үнэн → **B**.

> 💡 Хэрвээ `score >= 60`-ийг эхэнд нь бичвэл 95 оноо ч «D» болно — **дараалал чухал!**

## 💻 Нөхцөл нэгтгэх
```cpp
if (age >= 13 && age <= 19) cout << "Өсвөр нас";
if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') cout << "Эгшиг";
```

## 💻 Тэгш эсвэл сондгой
```cpp
if (n % 2 == 0) cout << "EVEN";
else            cout << "ODD";
```

## 🧠 Гурван тооны хамгийн их нь
```cpp
int a, b, c;
cin >> a >> b >> c;
int mx = a;
if (b > mx) mx = b;
if (c > mx) mx = c;
cout << mx;
```
«Одоогийн хамгийн их»-ийг хадгалаад, шинэ тоо бүрийг түүнтэй харьцуулна — энэ санааг дараа массивт ч ашиглана.

## ⚠️ Түгээмэл алдаа
- `if (x = 0)` — `==` биш `=` бичих.
- Хэд хэдэн мөр бүхий үйлдэлд `{ }` хаалт тавихаа мартах — зөвхөн эхний мөр нь нөхцөлд хамаарна.
- `if (1 <= x <= 10)` — C++-д ингэж бичиж болохгүй! → `if (1 <= x && x <= 10)`.
- `if (...);` — хаалтын ард цэгтэй таслал тавих.
