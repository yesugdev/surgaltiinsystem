## 🎯 Энэ хичээлээр юу сурах вэ
- **Хувьсагч** гэж юу болох, түүнийг зарлах, утга оноох
- Гараас утга **унших** (`cin`) ба **хэвлэх** (`cout`)
- Хувьсагчийн нэрийн дүрэм

## 💡 Хувьсагч гэж юу вэ?
Хувьсагч бол **нэртэй хайрцаг** юм. Хайрцагт нэг утга хадгална, дараа нь түүнийг нэрээр нь дуудаж ашиглана, шаардлагатай бол шинэ утгаар сольж болно.

```
   ┌─────┐      ┌─────┐
   │ 15  │      │  3  │
   └─────┘      └─────┘
     age         count
```

## 💻 Зарлах ба оноох
```cpp
int age;          // зарлах: "age" нэртэй бүхэл тооны хайрцаг
age = 15;         // оноох: хайрцагт 15 хийх
int count = 3;    // зарлах + оноох нэг дор

age = age + 1;    // хуучин утгыг ашиглан шинэчлэх → 16
cout << age << " " << count << endl;   // 16 3
```
> ⚠️ `=` нь математикийн «тэнцүү» **биш**, «баруун талын утгыг зүүн талын хувьсагчид **хийх**» гэсэн үг. Тиймээс `age = age + 1` зөв бичлэг.

## 💻 Оролт унших, гаралт хэвлэх
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;                 // хоёр тоо унших (зай эсвэл шинэ мөрөөр тусгаарлагдсан)
    cout << "Нийлбэр: " << a + b << endl;
    cout << a << " " << b << "\n"; // "\n" ба endl хоёулаа шинэ мөр
    return 0;
}
```
`cin >>` нь хоосон зай, шинэ мөрийг алгасаад дараагийн утгыг уншина.

## 🧠 Хоёр хувьсагчийн утгыг солих
`a = 3, b = 7` бол солиод `a = 7, b = 3` болгоё. Шууд `a = b; b = a;` гэвэл хоёулаа 7 болно! Гурав дахь «туслах хайрцаг» хэрэгтэй:
```cpp
int t = a;   // t = 3
a = b;       // a = 7
b = t;       // b = 3
```
(C++-д бэлэн `swap(a, b);` функц ч бий.)

## 📏 Нэрийн дүрэм
| Зөв | Буруу | Яагаад |
|---|---|---|
| `score`, `max_value`, `x1` | `1x` | Тоогоор эхэлж болохгүй |
| `totalSum` | `total sum` | Зай байж болохгүй |
| `myInt` | `int` | Түлхүүр үгийг нэр болгож болохгүй |

**Утгатай нэр** өг: `s` гэхээс `sum` гэвэл кодоо уншихад амар.

## ⚠️ Түгээмэл алдаа
- Утга оноогоогүй хувьсагчийг ашиглах — дотор нь «хог» утга байж болно.
- `cin << a` гэж сумыг буруу тийш бичих (`cin >>`, `cout <<`).
- `Age` ба `age` — өөр хувьсагч.
