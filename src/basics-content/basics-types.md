## 🎯 Энэ хичээлээр юу сурах вэ
- C++-ийн үндсэн **өгөгдлийн төрлүүд**
- Төрөл бүрийн **хязгаар** — хэзээ `long long` хэрэгтэй вэ
- Бутархай тоог **нарийвчлалтай хэвлэх**

## 💡 Яагаад төрөл хэрэгтэй вэ?
Хайрцаг бүр өөр зүйл хадгалахад зориулагдсан: өндөгний хайрцагт өндөг, шилэн саванд ус. Компьютерт ч мөн адил — хувьсагч бүр **ямар төрлийн** утга хадгалахаа мэддэг байх ёстой.

## 📋 Үндсэн төрлүүд
| Төрөл | Юу хадгалах | Жишээ | Хязгаар (ойролцоо) |
|---|---|---|---|
| `int` | Бүхэл тоо | `42`, `-7` | ±2·10⁹ |
| `long long` | Том бүхэл тоо | `9000000000` | ±9·10¹⁸ |
| `double` | Бутархай тоо | `3.14`, `-0.5` | ~15 оронтой нарийвчлал |
| `char` | Нэг тэмдэгт | `'A'`, `'7'`, `'?'` | |
| `bool` | Үнэн/худал | `true`, `false` | |
| `string` | Тэмдэгт мөр | `"Сайн уу"` | |

```cpp
int n = 25;
long long big = 3000000000LL;
double pi = 3.14159;
char grade = 'A';
bool passed = true;
string name = "Бат";      // #include <string>
```

## ⚠️ Халих (overflow)
`int` 2 147 483 647-оос их тоо хадгалж чадахгүй — хэтэрвэл **буруу** (ихэвчлэн сөрөг) тоо гарна!
```cpp
int a = 100000, b = 100000;
cout << a * b;                 // ❌ 1410065408 гэх мэт буруу хариу
long long c = 1LL * a * b;     // ✅ 10000000000
```
> 💡 **Дүрэм:** хариу 2·10⁹-өөс их байж болзошгүй бол `long long` ашигла. `a * b`-г тооцохоос **өмнө** `long long` болгох хэрэгтэй (`1LL * a * b`).

## 💻 Бүхэл ба бутархай хуваалт
```cpp
cout << 7 / 2;      // 3    — хоёулаа int → бүхэл хуваалт (үлдэгдлийг хаяна)
cout << 7.0 / 2;    // 3.5  — нэг нь double → бутархай хуваалт
int s = 10, n = 4;
double avg = (double)s / n;   // 2.5 — төрлийг хувиргах (cast)
```

## 💻 Нарийвчлалтай хэвлэх
```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x = 2.0 / 3;
    cout << fixed << setprecision(2) << x << endl;   // 0.67
    printf("%.3f\n", x);                              // 0.667
}
```

## ⚠️ Түгээмэл алдаа
- Дундаж олохдоо `s / n` (int / int) гэж бичээд бутархай хэсгээ алдах.
- `char c = "A";` — нэг тэмдэгт **дан** хашилтад: `'A'`; мөр **давхар** хашилтад: `"A"`.
- Их тоог `int`-д хадгалж халих.
