## 🎯 Энэ хичээлээр юу сурах вэ
- **Шугаман хайлт** — нэг нэгээр шалгах
- **Хоёртын хайлт** — эрэмбэлэгдсэн массивт хагаслан хайх
- Хоёр аргын **хурдыг** харьцуулах

## 💡 Шугаман хайлт
Ширээн дээр холилдсон картуудаас «7»-г олохын тулд нэг нэгээр нь харна. Энэ бол **шугаман хайлт**.
```cpp
int pos = -1;
for (int i = 0; i < n; i++) {
    if (a[i] == x) {
        pos = i;          // олдлоо
        break;            // эхний олдсоноор зогсоно
    }
}
// pos = -1 бол олдоогүй
```
n элементтэй массивт хамгийн муу тохиолдолд **n** алхам.

## 💡 Хоёртын хайлт
📖 Толь бичгээс «нар» үгийг хайхдаа эхний хуудаснаас нэг нэгээр эргүүлэхгүй — **дунд** нь нээгээд, хэрэгтэй хагас руугаа шилжинэ. Энэ нь массив **эрэмбэлэгдсэн** үед л ажиллана.

```
x = 23 хайя:   [ 2  5  8  12  16  23  38  56  72  91 ]
алхам 1: дунд = 16  →  23 > 16  → баруун хагас
         [ 23  38  56  72  91 ]
алхам 2: дунд = 56  →  23 < 56  → зүүн хагас
         [ 23  38 ]
алхам 3: дунд = 23  →  олдлоо! ✓
```

## 💻 Хоёртын хайлтын код
```cpp
bool found = false;
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = (lo + hi) / 2;
    if (a[mid] == x) { found = true; break; }
    else if (a[mid] < x) lo = mid + 1;    // баруун хагаст
    else hi = mid - 1;                     // зүүн хагаст
}
```
C++-д бэлэн функц бий:
```cpp
#include <algorithm>
bool ok = binary_search(a.begin(), a.end(), x);
```

## 🧠 Хэр хурдан бэ?
Алхам бүрт хайх хүрээ **хоёр дахин** багасна:
| Элементийн тоо | Шугаман (хамгийн муу) | Хоёртын (хамгийн муу) |
|---|---|---|
| 1 000 | 1 000 | 10 |
| 1 000 000 | 1 000 000 | 20 |
| 10⁹ | 10⁹ | 30 |

Тиймээс олон асуулгад хоёртын хайлт хамаагүй хурдан.

## ⚠️ Түгээмэл алдаа
- **Эрэмбэлэгдээгүй** массивт хоёртын хайлт хэрэглэх → буруу хариу.
- `lo = mid` эсвэл `hi = mid` гэж бичээд төгсгөлгүй давталтад орох.
- Шугаман хайлтад олдмогц `break` хийхээ мартаж, **сүүлийн** олдсоныг авах.
