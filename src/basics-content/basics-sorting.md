## 🎯 Энэ хичээлээр юу сурах вэ
- **Эрэмбэлэлт** гэж юу вэ, яагаад хэрэгтэй вэ
- **Bubble sort** — хамгийн энгийн эрэмбэлэх арга
- C++-ийн бэлэн `sort()` функц, буурахаар эрэмбэлэх

## 💡 Санаа
Биеийн тамирын хичээлээр сурагчдыг **өндрөөр нь** эгнүүлдэг. Эрэмбэлсэн өгөгдөлд:
- хамгийн бага/их нь шууд эхэнд/төгсгөлд,
- **хоёртын хайлт** хийж болно,
- ижил утгууд хөрш зэргэлдээ байрлана.

## 💡 Bubble sort
Хөрш хоёр элементийг харьцуулж, буруу дараалалтай бол **сольно**. Нэг удаа дуусахад хамгийн том нь «хөөс шиг» төгсгөл рүүгээ хөвж гарна.
```
[5, 2, 4, 1]
1-р тойрог: 5↔2 → [2,5,4,1];  5↔4 → [2,4,5,1];  5↔1 → [2,4,1,5]  ✓ 5 байрандаа
2-р тойрог: 2,4 зөв;  4↔1 → [2,1,4,5]                          ✓ 4 байрандаа
3-р тойрог: 2↔1 → [1,2,4,5]                                     ✓ дууслаа
```
```cpp
for (int i = 0; i < n - 1; i++)
    for (int j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
```
Ойролцоогоор **n²** харьцуулалт: n = 1000 үед сая — болно, харин n = 100 000 үед 10¹⁰ — хэт удаан!

## 💻 sort() — хурдан бэлэн функц
```cpp
#include <algorithm>
#include <vector>
using namespace std;

vector<int> a = {5, 2, 4, 1};
sort(a.begin(), a.end());                    // өсөхөөр: 1 2 4 5
sort(a.begin(), a.end(), greater<int>());    // буурахаар: 5 4 2 1
```
`sort` нь **n log n** орчим алхам хийдэг — n = 10⁶ үед ч хурдан.

## 🧠 Эрэмбэлсний дараах хэрэглээ
**Медиан (дундах утга):** сондгой n элементийг эрэмбэлээд `a[n / 2]`.
```cpp
sort(a.begin(), a.end());
cout << a[n / 2];          // [1, 3, 7, 8, 9] → 7
```
**Хамгийн их 3:** буурахаар эрэмбэлээд эхний 3.

## 💻 Тэмдэгт мөр эрэмбэлэх
```cpp
string s = "banana";
sort(s.begin(), s.end());          // "aaabnn"
vector<string> w = {"pear", "apple", "fig"};
sort(w.begin(), w.end());          // apple fig pear — толь бичгийн дараалал
```

## ⚠️ Түгээмэл алдаа
- `sort(a, a + n)` (энгийн массивт) ба `sort(a.begin(), a.end())` (vector)-ийг андуурах.
- Том өгөгдөлд bubble sort ашиглаж хугацаа хэтрүүлэх.
- Эрэмбэлсний дараа анхны байрлал алдагддагийг мартах.
