## 🎯 Энэ хичээлээр юу сурах вэ
- Өмнөх бүх хичээлээ **нэгтгэж** бодлого бодох
- **Хоёр заагч** — эрэмбэлсэн массивт хурдан хайх
- **Динамик программчлал (DP)**-ын анхны санаа
- Хугацааны хязгаарт багтах **хурдан** шийдэл сонгох

## 💡 Бодлого бодох 5 алхам
1. **Унш** — оролт, гаралт, хязгаарыг (n ≤ ?) анхааралтай.
2. **Жишээг гараар** бод.
3. **Энгийн (brute force)** шийдлийг бод — зөв ажиллах уу?
4. **Хурдыг тооц:** компьютер секундэд ~10⁸ үйлдэл хийнэ.
5. **Кодло, шалга** — жишээ болон захын тохиолдлууд (n = 1, бүх тоо ижил…).

| n-ийн хязгаар | Тохирох шийдэл |
|---|---|
| n ≤ 1 000 | n² — давталт доторх давталт болно |
| n ≤ 100 000 | n log n — `sort`, хоёртын хайлт |
| n ≤ 10⁶ ба түүнээс их | n — нэг давталт |

## 💡 Хоёр заагч
**Бодлого:** эрэмбэлсэн массивт нийлбэр нь x болох хоёр тоо байна уу?

Энгийн арга — бүх хосыг шалгах — n² (n = 10⁵ үед 10¹⁰ — удаан!). Илүү ухаалаг арга: нэг заагчийг **эхэнд**, нөгөөг **төгсгөлд** тавина.
```cpp
sort(a.begin(), a.end());
int i = 0, j = n - 1;
bool found = false;
while (i < j) {
    long long s = (long long)a[i] + a[j];   // int + int халихаас сэргийлнэ
    if (s == x) { found = true; break; }
    if (s < x) i++;      // нийлбэр бага → томруулах хэрэгтэй
    else j--;            // нийлбэр их → багасгах хэрэгтэй
}
```
Алхам бүрт нэг заагч хөдөлнө → нийт **n** алхам (+ эрэмбэлэх n log n).

## 💡 Динамик программчлал: шатаар өгсөх
**Бодлого:** n шаттай шат. Нэг алхмаар 1 эсвэл 2 шат өгсөнө. Дээр гарах хэдэн янзын арга бий вэ?

n-р шатанд хүрэхийн тулд сүүлийн алхам нь (n−1)-ээс 1 шат эсвэл (n−2)-оос 2 шат байна:
`ways[n] = ways[n−1] + ways[n−2]`, `ways[0] = 1`, `ways[1] = 1`.

| n | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| ways | 1 | 1 | 2 | 3 | 5 | 8 |

```cpp
vector<long long> ways(n + 1);
ways[0] = 1;
if (n >= 1) ways[1] = 1;
for (int i = 2; i <= n; i++) ways[i] = ways[i - 1] + ways[i - 2];
cout << ways[n];
```
Рекурсийн хичээлийн Фибоначчитай адил ч, хариуг **хадгалж** дахин тооцоолохгүй тул хурдан. Энэ бол DP-ийн гол санаа: **жижиг бодлогын хариуг хадгалж, том бодлогод ашигла.**
