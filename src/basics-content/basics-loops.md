## 🎯 Энэ хичээлээр юу сурах вэ
- Үйлдлийг олон дахин хийх: `for`, `while`
- **Тоолуур** ба **хуримтлуур** (нийлбэр) ашиглах
- `break`, `continue`

## 💡 Санаа
1-ээс 100 хүртэлх тоог хэвлэхийн тулд 100 мөр `cout` бичих үү? Үгүй! **Давталт** нэг кодыг олон удаа ажиллуулна.

## 💻 for давталт
```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
// 1 2 3 4 5
```
| Хэсэг | Утга |
|---|---|
| `int i = 1` | Эхлэл — нэг удаа |
| `i <= 5` | Нөхцөл — үнэн байх хүртэл давтана |
| `i++` | Алхам бүрийн дараа |

## 🧠 Нийлбэр олох (хуримтлуур)
```cpp
int n;
cin >> n;
long long sum = 0;              // хуримтлуурыг 0-ээр эхлүүл
for (int i = 1; i <= n; i++) {
    sum += i;                   // i-г нэмж хуримтлуулна
}
cout << sum;
```
n = 4 үед:
| i | sum |
|---|---|
| 1 | 1 |
| 2 | 3 |
| 3 | 6 |
| 4 | 10 |

## 💻 n тоо уншиж нийлбэрийг олох
```cpp
int n;
cin >> n;
long long total = 0;
for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    total += x;
}
cout << total;
```

## 💻 while давталт
Хэдэн удаа давтахаа **урьдчилан мэдэхгүй** үед тохиромжтой. Жишээ: тооны цифрийн тоо.
```cpp
int n = 4072, digits = 0;
while (n > 0) {
    n /= 10;        // сүүлийн цифрийг тасална
    digits++;
}
cout << digits;     // 4
```

## 💻 break ба continue
```cpp
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // тэгшийг алгасах
    if (i > 7) break;           // давталтаас гарах
    cout << i << " ";           // 1 3 5 7
}
```

## 💻 Давталт доторх давталт
```cpp
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= i; j++) cout << "*";
    cout << "\n";
}
// *
// **
// ***
```

## ⚠️ Түгээмэл алдаа
- **Төгсгөлгүй давталт:** `while (n > 0)` дотор n-ийг өөрчлөхгүй байх.
- `i <= n` ба `i < n`-ийг андуурах → нэг илүү/дутуу давтах.
- Хуримтлуурыг давталтын **дотор** `sum = 0` гэж эхлүүлэх.
- Их нийлбэрт `int` ашиглах (1 + 2 + … + 10⁶ ≈ 5·10¹¹ → `long long`).
