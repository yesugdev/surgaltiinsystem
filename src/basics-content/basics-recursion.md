## 🎯 Энэ хичээлээр юу сурах вэ
- **Рекурс** — өөрийгөө дууддаг функц
- **Суурь тохиолдол** ба **рекурсив алхам**
- Факториал, Фибоначчи, Ханойн цамхаг

## 💡 Санаа
🪆 **Матрёшка хүүхэлдэй**: том хүүхэлдэйг нээхэд дотор нь жижиг хүүхэлдэй, түүнийг нээхэд бүр жижиг… эцэст нь нээгддэггүй хамгийн жижиг нь гарна.

Рекурс ч мөн адил: том бодлогыг **ижил төрлийн жижиг бодлого** болгон хувааж, хамгийн жижиг нь (суурь тохиолдол) шууд хариутай.

Рекурсив функц бүр **хоёр хэсэгтэй**:
1. **Суурь тохиолдол** — шууд хариу буцаана (зогсох нөхцөл).
2. **Рекурсив алхам** — өөрийгөө **жижиг** утгаар дуудна.

## 💻 Факториал: n! = n × (n−1)!
```cpp
long long fact(int n) {
    if (n == 0) return 1;           // суурь: 0! = 1
    return n * fact(n - 1);         // рекурсив алхам
}
```

## 🧠 Хэрхэн ажилладаг вэ?
```
fact(4)
= 4 * fact(3)
= 4 * 3 * fact(2)
= 4 * 3 * 2 * fact(1)
= 4 * 3 * 2 * 1 * fact(0)
= 4 * 3 * 2 * 1 * 1 = 24
```
Дуудлага бүр «хүлээгдэж», суурь тохиолдолд хүрмэгц буцаад үржигдэнэ.

## 💻 Фибоначчи: F(n) = F(n−1) + F(n−2)
```cpp
long long fib(int n) {
    if (n <= 1) return n;           // суурь: F(0)=0, F(1)=1
    return fib(n - 1) + fib(n - 2);
}
```
> ⚠️ Энэ код n = 45 орчимд **маш удаан** — ижил утгыг олон дахин тооцдог. Давталтаар эсвэл хариуг хадгалж (DP) бодвол хурдан. Үүнийг «Ахисан алгоритм» хичээлд үзнэ.

## 💻 Ханойн цамхаг
3 шон, 1-р шонд n диск (том нь доор). Бүх дискийг 3-р шон руу зөөх; нэг удаад нэг диск, том дискийг жижгийн дээр тавьж болохгүй.

**Санаа:** n дискийг 1 → 3 зөөхийн тулд:
1. Дээд n−1 дискийг 1 → 2 зөө (3-ыг туслах болгон),
2. Хамгийн том дискийг 1 → 3 зөө,
3. n−1 дискийг 2 → 3 зөө.
```cpp
void hanoi(int n, int from, int to, int via) {
    if (n == 0) return;                 // суурь: зөөх диск алга
    hanoi(n - 1, from, via, to);
    cout << from << " " << to << "\n";
    hanoi(n - 1, via, to, from);
}
```
Нийт **2ⁿ − 1** алхам.

## ⚠️ Түгээмэл алдаа
- **Суурь тохиолдолгүй** рекурс → төгсгөлгүй дуудлага → програм унана (*stack overflow*).
- Рекурсив алхамд утгыг жижигрүүлэхгүй байх: `fact(n)` дотор `fact(n)` дуудах.
- Хэт гүн рекурс (10⁶ гүн) — stack хүрэлцэхгүй байж болно.
