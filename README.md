# YeSuvd Learning Platform

Багшийн үйл ажиллагааг автоматжуулах систем. **Модуль 1: Шалгалт.**

Технологи: Node.js 22 · Express 5 · MongoDB (Mongoose) · EJS

## Production (Docker)

Сервер дээр Docker Compose-оор (Caddy HTTPS + апп + MongoDB) ажиллуулах заавар: **[deploy/DEPLOY.md](deploy/DEPLOY.md)**

```bash
cd deploy && cp .env.example .env   # нууц утгуудыг бөглөнө
docker compose up -d --build
```

## Ажиллуулах (хөгжүүлэлт)

```bash
npm install
npm start          # эсвэл хөгжүүлэлтийн үед: npm run dev
```

Дараа нь http://localhost:3000 нээнэ. Анх асахад админ эрх автоматаар үүснэ:
**admin / admin123**. Нэвтэрсний дараа нууц үгээ заавал солино уу.

Туршилтын өгөгдөл (багш, анги, 3 сурагч, 1 шалгалт) нэмэх бол:

```bash
npm run seed:demo
```

Тохиргоо хийх бол `.env.example`-ийг `.env` нэрээр хуулж засна (`MONGODB_URI`, `SESSION_SECRET`, `PORT` гэх мэт).
Бодит орчинд `SESSION_SECRET`-ийг заавал тохируулна.

## Хичээл

Хичээл (`Subject`) нь системийн суурь объект: шалгалт бүр нэг хичээлд харьяалагдах бөгөөд цаашид
хичээлийн контент (материал, даалгавар) мөн хичээлд холбогдоно.

- Админ хичээлийг нэмж, багш нарт «Хичээл» хуудаснаас эсвэл багшийн засах хуудаснаас онооно. Нэг багш олон хичээл заах боломжтой.
- Багшаас хичээлийг нь хасвал тэр хичээлийн шалгалтууд түүнд харагдахаа болино (устахгүй).
- Архивласан хичээлээр шинэ шалгалт үүсгэхгүй, хуучин шалгалт, үр дүн хэвээр. Шалгалттай хичээлийг устгах боломжгүй.

## Хичээл (онол + даалгавар)

Хичээл нь нэг хичээлийн төрөлд харьяалагдах сэдэв бөгөөд **олон ангид** оноож болно.

- **Онол** — Markdown (гарчиг, жагсаалт, хүснэгт, код, зураг). Засахдаа шууд урьдчилан харна.
- **Хавсралт** — PDF, слайд, зураг г.м. Зургийг онол дотор `![](/files/…)` байдлаар оруулж болно.
- **Тест** — асуулт шалгалтынхтай ижил текст форматаар, автоматаар дүгнэгдэнэ. Дахин өгөх, зөв хариулт харуулах тохиргоотой.
- **Даалгавар** — заавар + сурагч файл (Word, PDF, зураг, код…) илгээнэ. Хугацаа, дээд оноо. Багш/админ файлыг
  хөтөч дээр нээж (PDF, зураг шууд; Word-ийг HTML болгон) оноо, сэтгэгдэл өгнө.
- **Дүнгийн хүснэгт** — хичээл тус бүрээр сурагч × даалгавар, CSV татах.
- **PowerPoint (.pptx)** онолын хавсралт болон сурагчийн илгээсэн файлыг хөтөч дотор слайд болгож зурна
  (`pptx-preview`); «▶ Үзүүлэх» — бүтэн дэлгэц, ← → товч, Esc. Хуучин `.ppt`-г `.pptx` болгож хадгалах шаардлагатай.
- Дүгнэх хуудсанд сурагчийн илгээсэн **бүх** файл (зураг, PDF, PPTX, Word) дараалан харагдана.
- Файлууд MongoDB GridFS-д хадгалагдана; эрхгүй хэрэглэгч нээх боломжгүй. Нэг файлын дээд хэмжээ `MAX_FILE_MB` (анхдагч 25).

**AI-аар нэг дор оруулах:** хичээлийн хуудасны «✨ AI-аар оруулах» → «AI prompt» хуулж AI-д өгөөд гаралтыг буулгахад
онол, бүх тест, даалгавар зэрэг орно:

```
=== ОНОЛ ===
## Гарчиг
Markdown агуулга...

=== ТЕСТ: Бататгах тест ===
1. Асуулт
A) ...
*B) Зөв хариулт

=== ДААЛГАВАР: Бие даалт ===
Оноо: 10
Даалгаврын заавар...
```

Задлагч: `public/lesson-parser.js` (тестийн хэсгийг `question-parser.js` задална), prompt: `src/ai-prompt.js`.

## Асуулт олноор оруулах

Шалгалтын хуудсан дээрх **«Олноор оруулах»** товчоор олон асуултыг текстээр буулгаж нэг дор оруулна.
Баруун талд шууд урьдчилан харж, алдааг мөр мөрөөр нь заана. Алдаа байвал нэг ч асуулт орохгүй.
**«AI prompt»** товч нь ChatGPT/Claude/Gemini-д хуулж өгөх бэлэн prompt харуулна (систем AI API-д холбогддоггүй).

```
1. Асуултын текст
A) Сонголт
*B) Зөв сонголт          ← * = зөв; хэд хэдэн * бол олон сонголттой
Оноо: 2                  ← заавал биш

2. Нээлттэй асуулт
Хариулт: Улаанбаатар | УБ   ← хоосон бол багш гараар дүгнэнэ
```

Задлагч (`public/question-parser.js`) хөтөч болон сервер хоёрт нэгэн зэрэг ашиглагддаг.

## Шалгалтын онцлог

- Асуултын төрөл: нэг сонголттой, олон сонголттой, нээлттэй хариулт.
- Нээлттэй асуултад зөв хариултуудыг урьдчилан оруулбал автоматаар (том/жижиг үсэг ялгахгүй) дүгнэнэ; оруулаагүй бол багш гараар оноо өгнө.
- Үргэлжлэх хугацаа, нээгдэх/хаагдах цаг; асуултын дарааллыг сурагч бүрт холих.
- Хариулт 10 секунд тутам болон өөрчлөлт бүрийн дараа автоматаар хадгалагдана — хуудас шинэчлэгдэх, интернэт тасрахад алдагдахгүй.
- Хугацаа дуусахад автоматаар илгээгдэнэ; сервер талд ч хугацааг шалгадаг тул хугацаа хэтрүүлж илгээх боломжгүй.
- Сурагч нэг шалгалтыг нэг л удаа өгнө. Зөв хариулт хөтөч рүү илгээгддэггүй.
- Сурагч шалгалт өгч эхэлсний дараа асуултыг өөрчлөх боломжгүй болно.
